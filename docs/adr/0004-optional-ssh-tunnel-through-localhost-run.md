# Optional ssh tunnel through localhost.run

`/remote start --tunnel ssh` runs the system `ssh` to open a localhost.run tunnel and stops it with the server. This refines ADR-0002 (no relay): the extension still runs no infrastructure, but for this option a third party relays and can read the conversation and access token. We accepted that because the alternatives either need an app and account on both devices (Tailscale) or break the event stream (Cloudflare Quick Tunnels do not support Server-Sent Events). localhost.run needs no install and no account, and we checked that SSE streams through it. It is never the default; Tailscale detection stays first. If `ssh` ends, remote turns off instead of restarting, because the free address changes and the QR code would be stale.
