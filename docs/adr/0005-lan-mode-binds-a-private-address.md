# LAN mode binds one private address over plain http

`/remote start --lan` (and the LAN choice in the `/remote` picker) makes the server listen on this machine's first private IPv4 address and pairs with `http://<address>:<port>`. This refines ADR-0002 (localhost bind behind a tunnel): for this option no tunnel is involved and the token travels in cleartext on the local network. We accepted that because people asked to connect a phone on the same Wi-Fi without installing Tailscale or relaying through a third party. To keep the exposure small, the server binds only that one private address (10.x, 172.16–31.x, 192.168.x), never `0.0.0.0` or a public address, it is never the default, and the start message warns that anyone on the network can read the traffic. Token lockout still applies. If the address changes, the person starts remote again and pairs again.
